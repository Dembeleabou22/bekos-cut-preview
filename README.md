# Bekos Cut — Tests & CI

Dieses Repo enthält nun einfache Unit‑Tests für die booking helper‑Funktionen und eine GitHub Actions CI, die die Tests bei jedem Push ausführt.

- `npm test` läuft Jest und erzeugt Coverage.
- `debug.html` enthält eine kleine Test‑UI zum Simulieren von Consent und blocked/ok Szenarien.
